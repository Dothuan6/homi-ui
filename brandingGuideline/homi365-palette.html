  • Không đặt chữ màu --teal-500 hay --teal-300 trên nền trắng. Chữ teal phải dùng --teal-700. Hai bậc sáng chỉ dành cho mảng nền, icon lớn và đồ hoạ.
  • Nút nền teal-500 phải dùng chữ --navy-900, không dùng chữ trắng (chữ trắng chỉ đạt 2.99:1). Nếu bắt buộc chữ trắng, đổi nền sang --teal-700.
  • --gray-400 không dùng cho nội dung quan trọng. Chỉ đạt ngưỡng chữ lớn — dành cho caption, placeholder, timestamp.
  • Không dùng màu đơn thuần để truyền tải trạng thái. Nhãn "Bất thường" cần cả màu đỏ lẫn chữ hoặc icon — quan trọng với nhóm người dùng cao tuổi và người rối loạn sắc giác.
  • Tỷ lệ dùng màu 60/30/10: 60% neutral (trắng, warm-50), 30% navy, 10% teal. Teal mất tác dụng điểm nhấn nếu phủ quá rộng.

05

CSS variables

Dán vào file token gốc. Nhóm semantic ở cuối cho phép đổi toàn bộ giao diện chỉ bằng cách trỏ lại token.

tokens.css
/* HOMI365 — design tokens */
:root{
  /* Brand — navy */
  --navy-900:#122544;
  --navy-700:#1B3358;
  --navy-600:#1E3A66;
  --navy-400:#4A6A9E;

  /* Brand — teal */
  --teal-700:#0F7F96;
  --teal-500:#1BA3BE;
  --teal-300:#4FB8CE;
  --teal-100:#D6E6EF;

  /* Neutral */
  --white:#FFFFFF;
  --warm-50:#FAF8F3;
  --gray-100:#F2F4F3;
  --gray-400:#8A93A3;
  --gray-800:#2B303A;

  /* Accent — chỉ dùng cho đồ hoạ */
  --wood-300:#D8B98F;
  --sky-200:#A8C4D8;

  /* Functional — đã hiệu chỉnh đạt AA */
  --success:#2F7A48;
  --warning:#965C0A;
  --error:#C0392B;
  --info:#0F7F96;

  /* Semantic */
  --bg:var(--white);
  --bg-alt:var(--warm-50);
  --bg-tint:var(--teal-100);
  --text:var(--gray-800);
  --text-muted:var(--gray-400);
  --text-invert:var(--white);
  --primary:var(--navy-600);
  --primary-hover:var(--navy-700);
  --on-primary:var(--white);
  --accent:var(--teal-700);
  --accent-hover:var(--teal-500);
  --on-accent:var(--white);
  --border:var(--gray-100);
  --border-strong:var(--navy-400);
  --focus-ring:var(--teal-700);
}
